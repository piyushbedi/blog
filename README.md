# piyushbedi.com

Personal blog built with Astro and hosted on GitHub Pages at [piyushbedi.com](https://piyushbedi.com).

## Local development

Requires Node.js 24.

```sh
npm ci
npm run dev
```

Run `npm run build` to generate the site in `dist/`, then `npm run preview` to preview the build locally.

## Deployment

Pushing to `main` automatically builds and deploys the site through GitHub Actions to GitHub Pages.
